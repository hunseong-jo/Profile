02 아이템 세부 메커니즘 (Dual-Outcome 설계)
기본 지급분과 순수 보험 증분을 명확히 분리한 무손실 하이브리드 패스

🔄 Case A: 반천장 실패 (픽뚫 발생) — 〈별자리 역행 전환〉

  • 적용 대상: 캐릭터 이벤트 기원(1·2) 및 묶음 기원 반천장에서 상시 5성(진, 치치, 각청, 모나, 다이루크, 타이나리, 데히야, 유메미즈키 미즈키)이 등장한 순간. (※ 모나 본인 픽뚫 시 전용 당황 대사 출력)
  • [선택 1: 별자리 역행 전환] (1~5돌 중복):
    • 상시 5성 중복 별자리 1개 회수 ➔ 주인 없는 스타라이트 총 30개 지급 (기본 10개 + 보험 순증 +20개 = +4뽑)
    • 다음 5성 천장 카운트(확천 상태) 즉시 +15스택 가산 (기대 가치 약 15뽑) + 모나의 위로 상자(농축 레진×3·경험책×30·30만 모라)
  • [선택 1+: 6돌 초과 풀돌 상시 픽뚫 특례]:
    • 주인 없는 스타라이트 총 75개 지급 (기본 25개 + 보험 순증 +50개 = +10뽑) + 천장 카운트 +20스택 가산 (가입분 포함 순증 33.75뽑 / 총수령 38.75뽑)
  • [미보유 최초 획득 / 별자리 유지]: 미보유 명함 획득 시 캐릭터는 유지하고 뒤얽힌 인연×5 + 천장 +10스택 지급(순증 18.75뽑). 기존 별자리 유지 선택 시 인연×10 + 농축 레진×2(순증 13.75뽑) 지급.

🎉 Case B: 반천장 승리 (한정 픽업 획득) — 〈무사고 만기 환급〉

  • 기획 의도: 반천장에서 바로 한정 캐릭터를 뽑았을 때도 결제 금액 이상이 환급되도록 손실 회피 장벽을 제거합니다.
  • 발동 시점: 5성 판정이 한정 픽업 캐릭터(50:50 승리 또는 별빛 포착)로 결정된 순간 자동 정산.
  • 무사고 만기 환급 보상:
    • 뒤얽힌 인연 ×5 (가입 시 600결정과 합산해 총 8.75뽑 순수 기원)
    • 〈축성의 서리〉 ×1: 성유물 해석기 핵심 재료 (부위별 필요 수량: 꽃/깃털 1개, 시계 2개, 왕관 3개, 성배 4개 — 1개 지급 시 즉시 꽃·깃털 제작 또는 성배 적립 보탬)
    • 픽업 5성 맞춤 육성 상자 ×1 (획득 캐릭터의 특성 비전서 ×20 + 필드 보스 돌파 소재 ×12 즉시 지급)

코드 예외 상황 (Edge Case) 시스템 방어 및 처리 로직 (Resolution Rule)
E-01 10연차에서 '픽뚫 상시 5성'과 '한정 5성'이 동시에 등장한 경우 배열 순서(Index 0~9)대로 먼저 나온 상시 5성에 역행 보험을 즉시 적용합니다. 뒤이어 나온 한정 5성으로 천장이 리셋된 직후, 새 반천장 사이클의 천장 카운트에 +15~20스택을 가산하며 2개 중첩 시에도 한 10연차 내 1개만 소모됩니다.
E-02 역행 선택 모달이 뜬 상태에서 네트워크 단절·강제 종료 발생 시 서버 트랜잭션 상태를 PENDING_RETRO_CHOICE로 보존합니다. 재접속 시 선택 모달을 즉시 재호출하며, 72시간 내 미선택 시 유저에게 가장 유리한 [선택 1: 별자리 역행 전환]을 자동 실행 후 우편 지급합니다.
E-03 패스 구매 후 해당 버전(42일) 종료 시까지 5성을 뽑지 못한 경우 보험 버프가 소멸하지 않고 다음 버전으로 1회 자동 이월됩니다. 이월 패스 보유 중 신규 버전 패스를 구매해 최대 2개까지 중첩 보유 가능하며, 픽뚫 발동 시 선입선출(FIFO)로 1개만 소모됩니다.
E-04 이미 '확정 픽업(직전 픽뚫 상태)'인 유저가 상품을 구매하는 경우 구매 시 안내 팝업을 노출하고, 버프 상태를 STANDBY로 보관했다가 확정 5성 획득 직후 돌아오는 다음 반천장(50:50) 사이클에 자동 ACTIVE 전환합니다.
E-05 보험 혜택 수령 후 스토어 악성 환불(청약철회 어뷰징) 시도 시 선지급 창세의 결정(600개) 사용 또는 보험 발동 시 청약철회 불가 플래그를 기록합니다. 강제 환불 발생 시 기존 정책과 동일하게 지급된 스택·스타라이트 환산 원석만큼 보유 원석을 마이너스(-) 차감합니다.
